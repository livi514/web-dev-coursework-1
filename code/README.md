# Web Development Coursework – README

## Project Description

This project is a four‑page informational website about the history, present, and future
of human space exploration. It is built using HTML5 and CSS3, with a focus on accessibility,
responsive design, and consistent layout. The site includes a homepage, a history page with
event cards and a photo gallery, a future timeline page, and a contact page with a form and
embedded Google Map.

The pages can be navigated using the navigation bar at the top of the screen.

This ZIP file contains all source code and assets for my website, including:
- HTML files
- CSS files
- Images and other assets
- This README file

The website has been deployed on my assigned Azure Lab VM as required.
